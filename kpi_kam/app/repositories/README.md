`AliasRepository` хранит таблицы `products` и `product_aliases` Phase 2.
Id товара устойчив к перестановке строк и нормализации имени; цены — текст Decimal.
Каталог `products.import_id` сохраняет SHA-256 источника для совместимости Phase 2.

`ApplicationRepository` расширяет ту же базу таблицами `employees`, `kpi_profiles`,
`imports`, `calculations`, `calculation_plans`, `shipments`. История сохраняет
версионированный полный снимок расчета, исходные сопоставления и имя сотрудника
на момент расчета; открытие не зависит от нового прайса, настроек или Excel-файла.
Снимки и вспомогательные строки пишутся одной транзакцией.
