# KPI KAM

Windows-приложение PySide6 с общим файлом продаж, отдельным внешним прайсом,
ролями КАМ/сопровождение, возвратами FIFO, выплатами и admin-панелью.
Существующая SQLite БД и старая история сохраняются при миграции.
Филимонова Анна включена в каталог; строки менеджера «тендер» исключаются.

Документация и команды запуска: [kpi_kam/README.md](kpi_kam/README.md).
Пошаговая работа: [RUNBOOK](kpi_kam/RUNBOOK.md).
Миграции: [MIGRATIONS](kpi_kam/MIGRATIONS.md).
Windows onedir-сборка: [build_windows.bat](kpi_kam/build_windows.bat),
[инструкция](kpi_kam/README.md#windows-сборка-pyinstaller-onedir) и
[GitHub Actions workflow](.github/workflows/build-windows.yml).
Требования: [KPI_KAM_Final_Codex_Prompt.md](KPI_KAM_Final_Codex_Prompt.md).
